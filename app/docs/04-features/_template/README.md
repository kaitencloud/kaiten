# Feature template

The template for a new feature, under `app/src/features/<name>/`.

- [`FEATURE_TEMPLATE.md`](./FEATURE_TEMPLATE.md): the structure of a feature, the role of each file, the naming patterns, the common mistakes and the model of a feature README.
- [`file-structure.txt`](./file-structure.txt): the folder tree of a feature, short enough to copy.

Only `components/`, `index.ts` and `README.md` are in every feature: add the other folders when the feature needs them. Every feature documents itself in `app/src/features/<name>/README.md`. After you write it, add the feature to the [entry table](../README.md).
