# 00 - Getting started

From a fresh clone to the console running on your machine, and the commands you use
once it does.

| Page | What it covers |
| --- | --- |
| [Setup](./setup.md) | Prerequisites, the one-command path with the whole local stack, the frontend-only path, environment variables, Clerk. |
| [Scripts](./scripts.md) | Every `pnpm run` script of `app/`, grouped: run, generate, check, test, end-to-end, coverage. |
| [Tech stack](./tech-stack.md) | The libraries and tools the console is built with, with their versions and roles. |

If you only want the console running: `cp .env.example .env` and `task dev` from
the repository root (see [Setup](./setup.md)). To send a change, follow the checklist
in [CONTRIBUTING.md](../../../CONTRIBUTING.md#before-you-open-a-pull-request).
